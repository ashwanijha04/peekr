Features

Everything you need to debug agents

⚡

Zero config

One call to instrument() patches OpenAI and Anthropic. No wrappers, no SDK changes, no env vars.

🔗

Automatic nesting

Spans link to their parents automatically via Python's ContextVar. Async agents work out of the box.

📦

No backend required

Traces write to a local JSONL file. No servers, no accounts, no data leaving your machine.

🎯

@trace decorator

Wrap any function — sync or async — to make it a traced span. Captures inputs, outputs, and errors.

🔌

Custom exporters

Ship spans to any backend by implementing a single export(span) method.

🔍

CLI viewer

Render the full trace tree in your terminal. Use --io to see every input and output.
