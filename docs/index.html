Four problems peekr solves

Every agent developer hits these walls. Peekr turns guesswork into evidence.

🔍

"My agent gave the wrong answer"

See the exact prompt that was sent — not what you think was sent, what was actually sent. Spot bad tool output before it reaches the LLM.

agent.run  2100ms
   └─ tool.fetch_user  12ms
         in:  {"user_id": 42}
         out: null                     ← user not found, agent didn't check
   └─ openai.chat [gpt-4o]  2088ms
         in:  [{"role": "system", "content": "User: null..."}]
⏱️

"My agent is too slow"

The trace shows exactly where time is spent. The bottleneck is almost never the LLM.

agent.run  4300ms
   └─ tool.search_web  3800ms   ← 88% of total time
   └─ openai.chat        490ms
💸

"My API bill is too high"

Token counts per trace reveal the pattern. Growing tokens across runs means unbounded history — summarize after 5 turns and cut costs 60–80%.

Trace 1:  18,432 tokens
Trace 2:  21,104 tokens
Trace 3:  24,891 tokens   ← unbounded growth
🐛

"It works locally but fails in prod"

The trace shows what tools actually returned. The agent logic is usually fine — the data pipeline isn't.

tool.fetch_inventory  8ms
   in:  {"sku": "ABC-123"}
   out: []   ← empty in prod, populated locally

Two lines. No config.

agent.py
import peekr
peekr.instrument()  # patches OpenAI + Anthropic automatically

from peekr import trace
import openai

# Wrap your tools to include them in the trace tree
@trace
def search_web(query: str) -> list:
    return fetch_results(query)

# LLM calls traced automatically — no changes needed
openai.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "..."}]
)

Built for developers

⚡

Zero config

One call patches OpenAI and Anthropic. No wrappers, no accounts, nothing to deploy.

🔗

Automatic nesting

Spans link to parents via ContextVar. Works across async without manual passing.

📦

No backend

Writes to a local JSONL file. Nothing leaves your machine until you want it to.

🎯

@trace decorator

Wrap any function — sync or async — to capture inputs, outputs, latency, and errors.

🔌

Custom exporters

Implement one method to ship spans to any backend you choose.

🔍

CLI viewer

peekr view --io traces.jsonl renders the full tree with inputs and outputs.
